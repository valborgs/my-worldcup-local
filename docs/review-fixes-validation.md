# PR #30 리뷰 후속 수정

## 수정

- Android가 반환하는 `denied` / `permanentlyDenied`를 권한 안내에 매핑한다.
  기존 enum 이름도 지원한다. `alreadyBusy`, `invalidState`, `connectionFailed`는
  전용 한국어·일본어·영어 안내를 추가했다. 언어별 리소스는 327개다.
- 현재 언어의 기본 샘플 제목·설명에 일치하는 ID를 저장소에 전달한다.
  저장된 원문 검색과 OR로 합친 뒤 개수·정렬·페이징을 적용한다.
  삭제된 샘플은 반환하지 않으며 중복 결과를 만들지 않는다.
  검색 화면을 연 상태에서 언어가 변경되면 검색 결과도 갱신한다.
- Android 문자열 생성 시 역슬래시·따옴표·제어문자·선행 `@`/`?`를 처리하고
  XML 요소용 escaping을 별도로 적용한다.

## 검증

- 수정 전 권한 안내, Android 특수문자, 추가 샘플 검색 테스트 실패를 확인했다.
- 전체 앱·패키지 테스트 291개 통과.
- SQLite로 검색 개수·페이지 경계·중복·삭제·빈 검색어·SQL 입력을 검증했다.
- 일본어·영어 검색 위젯 테스트 및 열린 화면의 한국어 전환 테스트를 통과했다.
- 정적 분석 오류 없음. 자세한 에뮬레이터 검증 범위는 기존 언어별 문서에 있다.
- 디버그 APK 빌드 성공. 별도 특수문자 리소스를 `aapt2 compile/link`로 빌드하고
  리소스 덤프에서 따옴표·역슬래시·`@`·`?`·XML 특수문자의 원문 보존을 확인했다.
