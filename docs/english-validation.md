# 영어 지원 검증

검증일: 2026-09-16. 브랜치: `codex/issue-29-localization-setup`.

## 구현

- `app_en.arb`에 한국어 원본과 동일한 324개 리소스를 제공한다.
- 한국어가 기본/fallback이며 영어 시스템 언어에서는 영어를 선택한다.
- 온보딩, 화면·버튼, 검증·오류, 전송 상태, 기본 샘플 이름, 공유 문구,
  접근성 안내, Android 앱 이름과 iOS 앱 이름·권한 안내를 포함한다.
- 재시도 대기 시간은 `1 second` / `2 seconds`처럼 ICU 복수형을 적용한다.
- 작은 화면에서 발견한 사진 추가 창의 영어 버튼 넘침을 재현 테스트로
  확인한 뒤, 공간이 부족하면 버튼을 세로로 배치하도록 수정했다.

## Android 에뮬레이터

Android 17 / API 37의 `emulator-5554`에서 시스템 언어 순서를
`en-US,ja-JP`로 변경하고 디버그 APK를 설치했다.
기본 화면과 780×1560(320dp 너비) 화면에서 다음을 확인했다.

- 앱 제목, 기본 샘플 제목, 목록 이동 및 도움말·추가 메뉴
- 온보딩 5페이지의 제목·본문·버튼·페이지 접근성 안내
- 작성 화면의 입력 안내·빈 값 오류·후보 수·사진 선택 버튼
- 사진 추가 창, 작성 취소 확인 창
- 수정된 APK 재설치 후 사진 추가 창의 버튼 넘침 해소

검증 중 문의나 파일을 외부로 전송하지 않았고 새 월드컵을 저장하지 않았다.
화면 크기 임시 설정은 검증 후 복원했다.

## 자동 검증

- 전체 앱·패키지 테스트 276개 통과 후, 사진 창 수정과 회귀 테스트 2개를
  추가하고 편집 패키지 19개를 재검증했다. 총 278개 테스트가 통과했다.
- ARB 키·placeholder 일치, 빈 값 및 한국어·일본어 표시 문자열 잔류 검사
- 영어 미국/영국 선택, 한국어 기본값 및 미지원 언어 fallback
- 열린 온보딩의 한국어→일본어→영어 변경, 모든 메시지·샘플 후보 매핑
- 모의 문의 검증·접수 및 사용자/서버 콘텐츠 보존, 모의 주변 기기 인증 UI
- 작은 화면·큰 글자의 메뉴, 업데이트 안내, 사진 추가 창
- `flutter analyze --no-pub`: 오류 없음
- `flutter build apk --debug --no-pub`: 성공

## 범위와 한계

이미지 속 글자, 디버그 시드, 로그/진단 문자열, 사용자·서버 콘텐츠는
기존 합의대로 원문을 유지한다. 광고 등 외부 SDK 콘텐츠는 공급자가 관리한다.
모든 오류·전송 상태를 실제 기기로 유발한 것은 아니며 자동 테스트로 보완했다.
iOS는 리소스와 Xcode 등록을 완료했지만 Windows에서 실행 검증하지 않았다.
기본 샘플 검색은 저장된 한국어 원문을 기준으로 하므로 영어 표시 제목을
검색하는 기능은 별도 보완이 필요하다.
